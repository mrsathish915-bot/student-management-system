# 🎓 Student Management System

A simple and responsive **Student Management System** built using HTML, CSS, and JavaScript.

This project allows users to add, search, edit, and delete student records. Student data is stored in the browser using **Local Storage**, so the information remains available after refreshing the page.

---

## 🚀 Live Demo

👉 [View the Student Management System](https://mrsathish915-bot.github.io/student-management-system/)

---

## ✨ Features

- ➕ Add new student records
- ✏️ Edit existing student information
- 🗑️ Delete student records
- 🔍 Search students
- 🎓 Select department and academic year
- ✅ Mark students as Pass or Fail
- 💾 Store student data using Local Storage
- 📱 Responsive design for mobile and desktop
- 🌐 Hosted using GitHub Pages

---

## 🛠️ Technologies Used

- **HTML5** — Structure of the application
- **CSS3** — Styling and responsive design
- **JavaScript** — Application logic and interactivity
- **Local Storage** — Browser-based data storage
- **GitHub Pages** — Website hosting
